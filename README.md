# 过保提醒服务

在浏览器里完成：**拖入系统导出的原始续保数据 → 自动筛选整理并出分析报告 → 下载名单填写邮箱 → 上传 → 按提醒频率批量发送 Outlook 邮件和日历邀请**。

原来需要人工把“续保单明细导出表”整理成“维保日历数据”，现在由程序自动完成。

## 运行（Windows）

1. 把离线包 `Contract-Expire-Reminder.zip` **整个解压**到一个文件夹（不要在压缩包预览里直接双击）
2. 双击 `启动.bat`，浏览器自动打开 http://127.0.0.1:5000（端口被占用时自动换下一个）
3. 需要本机已登录 Outlook

离线包内置 Python 3.12 和全部依赖（`runtime/python`），**不需要安装 Python，也不需要联网下载任何东西**。
离线包由 `python tools/build_package.py` 生成（在能联网的机器上执行一次）。

服务只监听本机，不会被同网段其他电脑访问。页面右上角可切换中文 / English 界面（Excel 列名保持中文）。

## 使用流程

### ① 导入原始数据
先选**通知模式**：

| 模式 | 发给谁 | 范围 | 排列 | 默认语言 |
| --- | --- | --- | --- | --- |
| 客户通知（默认） | 负责该客户的同事 | 全部客户 | 按客户分类（卓越 > 战略 > 核心 > 价值 > 商业 > 未分类），同一最终客户相邻 | 中文 |
| 渠道续保通知 | 签约客户（总代）或二代 | 默认只含非卓越/战略/核心客户（可选包含） | 同一签约客户相邻，其中同一二代相邻 | 英文 |

渠道通知使用单独的邮件模板：面向合作伙伴，不含金额、内部联系人和内部链接。
**收件人相同的合同合并成一封**，正文用表格列出全部合同；渠道通知的 6/3/1 个月节点统一提前到当月 1 日，
让同一伙伴同月到期的合同在同一天合并发送。称呼用组内共同的二代，没有则用共同的签约客户。
同一合同两种模式的提醒互不影响，各自防重复。

再拖入续保单明细导出表（含“当前合同号”“服务结束”“目录价”等列），可选参数：

| 参数 | 默认 |
| --- | --- |
| 过保时间段 | 下一年 1 月 1 日 ~ 12 月 31 日 |
| 合同合计目录价门槛 | 大于 20000 美元 |
| 包含已 EOS 设备（EOS 时间不晚于过保时间） | 不包含 |
| 包含资产状态为“不再拓展” | 不包含 |
| 包含产品线LV1“数据中心能源及关键供电” | 不包含 |

整理规则：按 **当前合同号 + 服务结束 + 服务类型** 合并（目录价相加），每个组合是一条单独的提醒；合计目录价超过门槛的才保留。

### ② 分析报告
筛选过程（每一步去掉多少行）、按过保月份 / 维保类型 / 代表处 / 客户汇总、提醒名单明细。可导出 HTML 报告，可**下载待填写名单 (Excel)**：

- 【提醒名单】保留“客户分类”（渠道模式另有“签约客户”“二代”），同一组底色相同；只需填写黄色“邮箱名单”列（多个收件人用 `;` 分隔）和“邮件语言”列（中文 / English）；右侧带出产品明细（型号×报价项数量），会写进邮件
- 【填写说明】填写方法和示例
- 【产品明细】每条提醒包含的产品
- 【已排除】被过滤掉的行及原因
- 【筛选条件】本次参数和各步数量

上次填写过的邮箱和邮件语言会自动带出（客户通知按最终客户，渠道通知按签约客户+二代）。

### ③ 上传收件人名单
上传填好的 Excel（旧版“维保日历数据.xlsx”也能直接上传），可在页面上再修改邮箱。

### ④ 提醒计划与发送
五个选项可任意组合：

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 过保前 6 个月 | ✔ | Outlook 定时发送（节点当天 9 点） |
| 过保前 3 个月 | ✔ | 同上 |
| 过保前 1 个月 | ✔ | 同上 |
| 立即发送一次 | | 马上发送 |
| 过保当日写入日历 | | 全天日程写入自己的 Outlook 日历，并作为会议邀请发给收件人 |

已经过去的节点默认跳过，可选择“立即补发”（同一条提醒当下要发的多个节点合并为一封）。
成功发送/排定的节点记录在 `data/send_log.csv`，重复运行不会重复发送。

## 发信方式（设置页）

- **Outlook**（默认）：支持定时发送和日历邀请
- **SMTP**：只能立即发送邮件
- **模拟发送**：只记录不发信，用于试运行

邮件分中文版和英文版（按 Excel“邮件语言”列选择，日历邀请也随之切换），正文含产品型号和数量。
中英文的邮件标题、日历标题、HTML 正文模板都可在设置页修改，占位符：`{office} {customer} {contract_name} {expiry} {service_type} {contract_no} {amount} {amount_fmt} {products} {node_label} {days_left} {days_text}`。

## 本地数据

`data/` 目录：`settings.json` 设置、`recipients.json` 各客户邮箱名单记忆、`send_log.csv` 发送记录。
