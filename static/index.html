怎么填写

  1. 在第②步点击“下载待填写名单”，打开 Excel 的【提醒名单】工作表。Excel 的列名请保持中文，程序按列名识别。
  2. 只填写黄色的 邮箱名单 和 邮件语言 两列，其他列不要改。一行就是一条提醒（合同号 + 过保时间 + 维保类型）。
  3. 同一客户（渠道模式为同一签约客户 / 二代）的行排在一起、底色相同，收件人通常一样，可以整组复制。
  4. 多个收件人用英文分号 ; 分隔，可以填邮箱，也可以填 Outlook 能识别的“姓名 工号”。
  5. 邮件语言 客户通知默认“中文”、渠道通知默认“English”，可下拉切换。
  6. 留空的行不会发送；不需要提醒的行可以整行删除。保存后在下面上传。
