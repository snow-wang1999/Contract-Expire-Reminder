怎么填写

  1. 在第②步点击“下载待填写名单”，打开 Excel 的【提醒名单】工作表。
  2. 只填写黄色的 邮箱名单 列，其他列不要改。一行就是一条提醒（合同号 + 过保时间 + 维保类型）。
  3. 多个收件人用英文分号 ; 分隔，可以填邮箱，也可以填 Outlook 能识别的“姓名 工号”。
  4. 邮件语言 列默认“中文”，需要发英文版（邮件和日历邀请）的行下拉选择 English。
  5. 留空的行不会发送；不需要提醒的行可以整行删除。保存后在下面上传。
